# Enhancing-Windows-Security-with-Logon-Monitoring-and-Reporting

##Scenario:##
TechSecure, a mid-sized enterprise, faces increasing cyber threats targeting its Windows-based systems, particularly through unauthorized login attempts and malicious command executions. To address this, TechSecure implements an advanced security configuration strategy.

They use Event Viewer to analyze failed logins, leveraging Event ID 4625 to identify potential intrusions and track suspicious IP addresses. By deploying group policies, they enable command logging and process auditing, ensuring every executed command is documented. Automation through PowerShell scripts allows real-time tracking of successful logins and automated HTML reporting for a failed attempt.

This proactive approach not only mitigates security risks but also provides comprehensive insights into user activities. By strengthening its Windows security posture, TechSecure ensures the safety of its systems and enhances its credibility as a secure and reliable enterprise.
